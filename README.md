# SecureVault

A Django-based password manager focused on secure credential storage,
encryption, and web application security.

> 🚧 This project is currently under development.

## Overview

SecureVault is a password manager built as a portfolio project to
demonstrate backend development, application security, cryptography,
and software engineering practices.

## Tech Stack

- Python
- Django
- PostgreSQL
- HTML
- CSS
- JavaScript
